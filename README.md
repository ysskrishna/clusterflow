# Clusterflow

[![License: MIT](https://img.shields.io/github/license/ysskrishna/clusterflow)](https://github.com/ysskrishna/clusterflow/blob/main/LICENSE) [![Author site](https://img.shields.io/badge/author-ysskrishna.space-informational)](https://ysskrishna.space)

## Hypervisor-like Service for MLOps Platform

## Techstack used
- FastAPI
- SQLite
- Redis
- SQLAlchemy
- Docker


## Prerequisites

- Python 3.10+
- pip
- virtualenv
- docker


## Running the backend service
```
docker compose  -f docker-compose.yml up --build
```


The server will be available at `http://localhost:8081/`

### API Documentation

Access the Swagger UI documentation at `http://localhost:8081/docs`
